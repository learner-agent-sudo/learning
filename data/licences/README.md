# Open source licence texts

Generated by `scripts/extract_licences.py` from the SPDX License List data
(github.com/spdx/license-list-data). Do not edit by hand.

Each file holds one licence's text, split into its numbered sections, so the
software IP volume can show the clause it cites. The licences kept here allow
verbatim copies of their text or are dedicated to the public domain;
source-available licences are summarised in the site's own words and linked
instead. The text is the licence as its steward published it; the copy that
governs a component is the one that ships with it.
